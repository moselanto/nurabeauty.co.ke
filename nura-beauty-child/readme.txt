=== NURA Beauty Child ===

ALWAYS activate this child theme, not the parent "NURA Beauty".

Why: WordPress themes get updated. If you edit the parent theme directly, your
changes are wiped on the next update. The child theme sits on top of the parent
and keeps your customisations safe.

Where to customise:
1. Colours, fonts, logo, phone/WhatsApp, prices, homepage text
   -> Appearance > Customize > NURA Options (no code needed - nothing is hardcoded).
2. Custom CSS -> style.css in this folder (or Appearance > Customize > Additional CSS).
3. Custom PHP (filters/hooks) -> functions.php in this folder.

Setup order:
1. Upload and activate BOTH themes (parent first, then this child).
2. Go to Appearance > NURA Setup and run the two setup steps.
3. Open the Customizer and make it yours.
